# Hymns and Clefs
Hymns and Clefs is a game designed to have the player learn Major, Minor, Augmented, and Diminished chords so that they can evenually write them from chord notation only.

#Features
1. player character and enemies that can each deal damage to eachother
     - different player and enemy types depending on level and clef choice
2. Choice between Treble Clef and Bass Clef
3. Multiple difficulty levels
4. All human made artwork
5. Bosses at the end of each level
6. Musical elements
7. Ways to upgrade the player and the deck

#Known Bugs
1. the game will accept "wroge notes" where the note is actually the same, but appear at different places on the staff (ex. F sharp and G flat)
