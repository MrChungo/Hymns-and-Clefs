# Hymns and Clefs
Hymns and Clefs is a game designed to have the player learn Major, Minor, Augmented, and Diminished chords so that they can eventually write them from chord notation only.

#Features
1. player character and enemies that can each deal damage to each other
     - different player and enemy types depending on level and clef choice
2. Choice between Treble Clef and Bass Clef
3. Multiple difficulty levels
4. All human-made artwork
5. Bosses at the end of each level
6. Musical elements
7. Ways to upgrade the player and the deck

#Known Bugs
1. The game will accept "wrong notes" where the note is actually the same, but appears at different places on the staff (ex. F sharp and G flat)

#Download Instructions
1. Go to GitHub Hymns and Clefs
2. Look for "Releases" on the right side of the page and click the latest version
3. Under "Assets", download the version called "Source code (zip)."
4. Go into your files and unzip the Hymns and Clefs file
5. Open the top file and play the game.
